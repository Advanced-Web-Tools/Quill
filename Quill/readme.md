# Quill for AWT

**Build visually. Connect your data. Publish with confidence.**

Quill brings visual page building, reusable components and dynamic content to AWT. Create polished, responsive pages in one workspace, with precise design controls and a clear draft-to-publish workflow.

## Design without friction

- **Visual editing:** Live canvas, nested layers, drag-and-drop, contextual insertion and floating toolbars.
- **Responsive layouts:** Flexbox, grids, layout presets, device previews, zoom and fit-to-screen.
- **Precise controls:** Linked spacing and dimensions, visual corner radius, edge pinning, transforms and a 3×3 transform-origin selector.
- **Complete styling:** Colors, images, gradients, backgrounds, borders, layered shadows, filters and transitions.
- **Responsive states:** Device-specific styles, hover/focus states, explicit overrides and contextual resets.
- **Rich content:** Inline text formatting, line breaks, links, images, lists, tables and searchable Font Awesome icons.
- **Typography:** Google Fonts search and previews, available weights, italics and system fonts.

## Build more. Repeat less.

- **Shared components:** Create, reuse and edit components centrally. Published updates reach referenced pages without republishing each page. Detach local instances when needed.
- **Personal templates:** Save reusable starting points for new pages.
- **Animation Studio:** Record property changes as keyframes in an isolated preview. Edit tracks, timing, easing and triggers; reuse animations from a shared library.
- **Color palettes:** Named local, global and provider palettes with solid colors, gradients, page defaults and quick exploration.
- **Visual Action Builder:** Connect events, conditions, targets and action steps without writing interaction code.

## Connect real content

- **Database connections:** Map records to text and attributes. Select a single record, match a route parameter or display a sorted, limited collection.
- **Visual query builder:** Combine nested AND/OR filters, comparisons and typed or route-based values.
- **Flexible text:** Combine fields such as first and last name, add before/after content and keep authored fallbacks.
- **Page routes:** Create and assign routes from the dashboard or editor.

## Stay in control

- **Publishing:** Separate drafts, public previews, revision snapshots, history and restore.
- **Block version history:** Browse saved block changes, see their authors and restore individual versions from the floating toolbar.
- **Editing confidence:** Grouped Undo/Redo, configurable keyboard shortcuts, block and style copy/paste, optional autosave and save-conflict protection.
- **Personal workspace:** Light/dark/system appearance, default device, save preferences and configurable autosave intervals.
- **Organized dashboard:** Search pages, components, templates and external resources; manage routes and versions.

## Built for the AWT ecosystem

- **Media libraries:** Register image and video providers, with shared pickers and direct URL fallback.
- **Extensible by design:** Register blocks, properties, controls, actions and external resources through Quill's extension APIs.
- **External editing:** Edit provider pages and components, including block additions and structural changes, while preserving the provider source.
- **URPC rendering:** Structured JSON documents, Quill ↔ URPC conversion and runtime document hooks. Editor-only tools stay out of published pages.

## Get started

Install Quill with the AWT package installer, then open **Dashboard → Quill** at `/dashboard/quill`.

Requires **AWT 27+**, **Dashboard** and the **URPC API**. No npm build is required. Released under the **MIT license**.

For technical guides and development instructions, see the source repository documentation.
